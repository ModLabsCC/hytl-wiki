# Contributing

Sign in on HYTL.DEV to save a private draft, preview it and submit a public suggestion, or open a GitHub pull request. Submitting makes your article and chosen alias public. Do not include personal information, credentials or content you cannot license.

Keep the page folder's immutable ID when renaming a slug or adding a translation. Add aliases for renamed slugs. Translate the same page ID; record the source locale and its article revision. Shared taxonomy IDs and game IDs are language-neutral. Explain the source of factual changes and preserve uncertainty and conditions.

New first-party prose is contributed under CC BY4.0. Third-party text requires explicit reuse evidence, correct attribution and the original applicable license; third-party media requires a separate rights check. Do not infer permission from a URL or a text license. Do not copy foreign wiki prose into a pull request.

Run the independent validator before submitting. CI runs without production secrets. The private publisher validates again using its trusted application compiler; editing the public validator does not change the production security decision.
