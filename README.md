# HYTL Community Wiki

Original community-authored guides for [HYTL.DEV](https://hytl.dev). This is an independent public content repository, not the private application repository. Articles use stable page IDs and per-language Markdown. English is initially published; German is enabled as an authoring locale, with no invented translations.

See CONTRIBUTING.md and HYTL_MARKDOWN.md. Run `node validator/validate.mjs .` with Node24 or newer. Special live components render on HYTL.DEV, not natively on GitHub.

The initial five articles are independently written from verified observed release-index game facts. No other wiki's prose or media was copied. Every article identifies its source records and observation hashes.
